# 🗺️ DestinationSwipeCards — iOS App

DestinationSwipeCards is an iOS application built with **Swift + UIKit** that provides an interactive destination browsing experience using swipeable cards.

The project focuses on creating a clean, modern UI with smooth card interactions and reusable UIKit components.

## 📱 Features

* 🗺️ Browse travel destinations using swipeable cards
* 👆 Interactive card swipe gestures
* ❤️ Like / favorite destination interaction
* ❌ Skip destination interaction
* 🖼️ Destination images and information
* 📱 Responsive UI using Auto Layout
* 🎨 Clean and reusable UIKit components
* ⚡ Smooth user interactions
* 🧩 Modular and maintainable code structure

## 🛠️ Technologies Used

* **Swift**
* **UIKit**
* **Storyboard / XIB**
* **Auto Layout**
* **UICollectionView / UITableView**
* **UIViewController**
* **Gesture Handling**
* **MVC Architecture**
* **Xcode**

## 🚀 Getting Started

### Requirements

* macOS
* Xcode
* iOS Simulator or physical iPhone
* Swift

### Installation

Clone the repository:

```bash
git clone https://github.com/anilyadavjnt/DestinationSwipeCards.git
```

Open the project:

```bash
cd DestinationSwipeCards
open DestinationSwipeCards.xcodeproj
```

Select an iOS Simulator or connected iPhone and press:

```text
⌘ + R
```

to build and run the application.
